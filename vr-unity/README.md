# Unity VR Application

This directory contains the Unity source project developed as part of my Master's graduation project, **Adaptive VR Phobia Therapy System**.

The application provides an immersive virtual reality environment designed to support progressive exposure scenarios for glossophobia (fear of public speaking).

## Main Features

- Virtual waiting-room environment.
- Immersive public-speaking scenario with virtual audience members.
- Progressive exposure levels.
- Integration with the system's Firebase backend for session synchronization, as implemented in the project.
- Interaction with the therapist dashboard as part of the overall therapy system.

## Project Structure

- `Assets/` — project scenes, scripts, models, materials, and other assets.
- `Packages/` — Unity package configuration.
- `ProjectSettings/` — project configuration and settings.


## Related Application

The corresponding therapist web dashboard is available in the [`web-dashboard/`](../web-dashboard/) directory of the main repository.
